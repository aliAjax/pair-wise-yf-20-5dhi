# hxyfront-62008 受风况约束的烟花燃放联锁台

源提示词编号：10

面向烟花燃放编排师的**风况约束燃放联锁台**。预置四点、三段节目与两种风况；每个点火组登记扇区、最小安全半径、持续时间与备选点，切换风况后自动重算风漂移与有效危险区。

## 联锁规则

风漂移 = 风速 × 持续时间；有效危险区为从主点沿风向延伸的胶囊（半径＝最小安全半径，长度＝漂移）。出现以下任一情况即**整组拒绝**：

1. **漂移交叠**：与同时燃放的其他组相比，邻点主点进入本组下风有效危险区（组对双向各记一条，均落到点位与时刻）；
2. **持续越过节目段**：点火时刻落入段间空档/整场之外，或点火＋持续结束于所属节目段结尾之后；
3. **备选点同扇区**：备选点所属扇区与该组登记扇区（主点扇区）相同。

联锁为纯判定：**拒绝不自动改期、不自动切换备选点，原排期保持不变**；仅当所有点火组获准，才生成整场时间轴与总览表，否则展示落到点位与时刻的拒绝明细。

## 预置数据

- 四点：B1 东一号台（东）、B2 西二号台（西）、B3 南三号台（南）、B4 瞭望台（东，与 B1 同扇区用于备选点规则演示）
- 三段节目：Intro 00:00–00:50、Chorus A 00:50–01:50、Finale 02:00–03:20（01:50–02:00 为段间空档）
- 两种风况：弱风·西偏南30° 3m/s（G1/G2 漂移交叠）、强南风 9m/s（横向错开，交叠消失）
- 演示组中 G4 持续越过 Chorus A 段尾、G5 备选点与主点同扇区

## 数据存储

登记数据与当前风况仅保存在浏览器 localStorage（`hxyfront-62008:interlock:v1`），刷新或重开页面后保留；页内「恢复预置演示数据」可一键还原。
